#  Student Report Card (Python)

A simple Student Report Card program built using Python. It accepts marks for five subjects, calculates the total marks and percentage, and displays the student's grade based on their performance.

##  Features

-  Accepts student's name
-  Takes marks for five subjects
-  Calculates total marks
-  Calculates percentage
-  Assigns grades (A, B, C, D, fail)
-  Displays a simple report card

##  Technologies Used

- Python 3

##  Concepts Practiced

- Variables
- User input
- Arithmetic operators
- Conditional statements (`if`, `elif`, `else`)
- Formatted output using f-strings

##  How to Run

1. Clone this repository.

```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Open the project folder.

3. Run the program.

